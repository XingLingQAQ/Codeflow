与现有首页（Dashboard.tsx）的差异说明：
  • 取消大品牌卡（Logo + 「从想法到提交」口号 + 渐变横线）：首屏空间让给 Gate 收件箱与命令入口；品牌回归侧栏 Logo 一处。
  • 四个统计（项目/进行中/快照/今日事件）从品牌卡里的图标链降为问候语下的一行文字事实，不做统计卡片墙。
  • Gate 收件箱升为首屏第一块（有待审时），琥珀左缘 + 「去审批」胶囊，与项目页的 Gate 语言一致；无待审时该块整体消失，命令行上移。
  • 命令四块保留但压扁：图标 + 标题 + 一行描述，去掉品牌色小圆点装饰；「回到工作台」直接显示目的地（项目 · 阶段）。
  • 「进行中的工作流」去掉 MiniFlow 七点时间轴（也属于进度条类），改用与项目卡一致的阶段文字胶囊；待审的行用琥珀胶囊直接写「编码 · Gate 待审」。
  • Agent 五卡压缩为一行五个小卡：图标 + 名字 + 一句职责 + 开始对话，去掉角色 Badge 与分隔线堆叠。
  • 状态语言与项目页统一：状态 = 小圆点，阶段 = 文字胶囊，警示 = 琥珀，全部真实数据、取不到即隐藏。
