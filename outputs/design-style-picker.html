CodeFlow Workbench · 设计选型

四种大厂极简方向，选一个

同一张工作台（顶栏 FlowProgress + 七阶段 Rail + 阶段画布 + Agent 伴侣 + 状态栏），四种皮肤。布局完全相同，差异只在设计语言——重点看边线、颜色用量、圆角和层次的处理方式。

看完回复 A / B / C / D（可以加备注，比如「B 但蓝色收一点」）
A

纯黑白 · 高对比锐利

参照 Vercel / Geist

零颜色，黑就是主色。纯白底 + 一套灰阶 + 纯黑按钮和活动态；1px 发丝边框划分一切，圆角小（6px），阴影几乎不用。语义色只留审批琥珀和成功绿的极小用量。最接近当前代码库的 true-white 方向，改动最小。

B

钴蓝精密 · 单强调色

参照 Linear / Stripe

白底不变，给系统一枚精确的钴蓝。活动阶段、主按钮、焦点、选中态共用一个蓝，FlowProgress 活动段带一丝辉光，签名渐变顺势改为钴蓝→青（清掉紫色残留）。冷灰中性色 + 轻阴影，观感是精密仪表。这条与你们「渐变紫→cobalt 纠偏」的待决项直接对齐。

C

无边框填充 · 柔和暖白

参照 Notion / Slack 新版

把边框全部扔掉，用「面」分层。暖白纸面上，侧栏和 Agent 面板是圆角浅灰色块（悬浮岛），卡片是填充而非描边，圆角放大到 10px，阴影极浅。整体安静、亲和、文档感强——适合把 CodeFlow 表达成「和 AI 一起写作工程」而非「操作机器」。

D

石墨机房 · 深色指示灯

参照 Linear 深色 / Raycast

深色为主视觉，青色只做「灯」。石墨底上层次靠白透明描边和面板亮度差；唯一的颜色是电光青，只出现在活动阶段、流式光标、连接指示灯——像一间只有指示灯亮着的机房。注意：你们产品承诺是浅色默认，选这条意味着重开该决策（或只用作深色主题精修）。
